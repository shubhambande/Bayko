# Shubham ♥ Bayko — Romantic Website

Open `index.html` in a browser to preview it.

## Publish it
Upload the whole `bayko_romantic_website` folder to a static hosting service such as GitHub Pages, Netlify, or Vercel.

## Customize
All romantic text, choices, dates, and messages are inside `index.html`.
Your six uploaded photos are already included in `images/`.

Tip: replace the sample Instagram conversation and letter text with your real messages for an even more personal gift.
